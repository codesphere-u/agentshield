Frequently Asked Questions

Why run deterministic security checks instead of an LLM guard model?

Probabilistic LLM judges add 300–1200 ms latency and remain susceptible to adversarial bypasses. AgentShield enforces deterministic parsing, decoding, and policy invariants under 0.15 ms with zero external API keys.

How does AgentShield protect Python tools and MCP tool calls?

Decorate any tool with @guard_tool(runtime) or pass OpenAI/Anthropic/MCP tool payloads through ShieldedAgentRuntime. Untrusted RAG contexts cannot trigger privileged tools.

How does the audit ledger detect tampering?

AuditLedger appends sequential SHA-256 hash-linked entries. Calling verify_integrity() detects tampered summaries, altered parameters, or deleted audit entries immediately.
